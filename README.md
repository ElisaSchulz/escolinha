# escolinha

## Rodízio de Organistas (`rodizio.html`)

Ferramenta para montar o rodízio mensal de organistas das igrejas (culto + Reunião de Jovens e Menores), substituindo o processo manual no Excel.

**Link:** https://elisaschulz.github.io/escolinha/rodizio.html — funciona no celular e no computador, sem instalar nada.

**Como usar (4 passos na tela):**

1. **Escolha a igreja** — as 7 igrejas já vêm cadastradas, cada uma com sua cor. Para mudar organistas, dias de culto ou a cor, toque em "Mudar organistas, dias de culto ou cor". Dá para adicionar igrejas em "+ Nova igreja".
2. **Escolha o mês** com as setas ◀ ▶.
3. **Monte o rodízio** — quem começa já vem escolhido para continuar de onde parou no mês anterior.
4. **Confira e baixe a imagem** — toque em qualquer nome para trocar a organista, remova ou inclua datas, preencha Ensaio e Limpeza e toque em "Baixar imagem do rodízio".

Tudo fica salvo automaticamente no próprio aparelho.
