# escolinha

## Rodízio de Organistas (`rodizio.html`)

Ferramenta para gerar o rodízio mensal de organistas das igrejas (culto + Reunião de Jovens e Menores), substituindo o processo manual no Excel.

**Como usar:** basta abrir o arquivo `rodizio.html` com dois cliques em qualquer navegador (Chrome, Edge, Firefox). Não precisa de internet nem de instalação.

1. Escolha a igreja (as 7 igrejas das planilhas já vêm cadastradas; dá para adicionar outras).
2. Confira os dias de culto e a lista de organistas — a lista pode ser editada livremente, uma por linha, na ordem do rodízio.
3. Escolha o mês, o ano e quem começa a meia hora, e clique em **Gerar rodízio**.
4. Para exceções, clique em qualquer nome na prévia e troque a organista; dá para adicionar ou remover datas.
5. Clique em **⬇ Baixar PNG** para salvar a imagem pronta para enviar.

As configurações e os rodízios gerados ficam salvos no próprio navegador.
